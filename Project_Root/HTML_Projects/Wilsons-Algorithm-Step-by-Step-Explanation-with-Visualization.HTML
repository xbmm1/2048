Wilson's Algorithm: Step-by-Step Explanation with Visualization

    • Algorithm Steps

    1. Initialize the grid: The maze starts fully walled.
    2. Pick a random starting cell: This cell becomes the first path cell.
    3. Randomly select an unvisited cell: This cell will perform a random walk.
    4. Perform a loop-erased random walk: Randomly move to neighbors until a visited cell is reached, erasing loops.
    5. Add the loop-erased path to the maze: Mark all cells in the path as part of the maze.
    6. Repeat steps 3-5: Continue until 50% of cells are part of the maze.
