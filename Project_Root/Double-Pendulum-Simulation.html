Interactive Double Pendulum Simulation

This simulation shows a double pendulum. It demonstrates chaos theory: very small changes in the starting angles of the pendulums cause drastically different motions over time. You can use the sliders below to set the starting angles (in degrees) of each pendulum arm, then watch how the system evolves.

Notice how unpredictable and complex the motion becomes, even though the system is governed by simple physics!

What this program does each iteration (or frame):

  1. Update the physics of the pendulum (update function):
    The program calculates the angular accelerations (a1_a and a2_a) of the two pendulum arms using physics formulas derived from Newton’s laws for a double pendulum.
    - These formulas take into account:
        - Gravity pulling down on the masses.
        - The current angles of the arms (a1 and a2).
        - The current angular velocities (a1_v and a2_v).
        - The lengths of the rods and the masses.
    Then, it updates the angular velocities by adding the accelerations:
    a1_v = a1_v + a1_a
    a2_v = a2_v + a2_a
    Next, it updates the angles by adding the velocities:
    a1 = a1 + a1_v
    a2 = a2 + a2_v
    A small damping factor (like friction) is applied by multiplying velocities by 0.999 to slowly reduce the motion over time.
  2. Calculate the positions of the pendulum bobs:
    Using the updated angles, the program calculates where each pendulum bob is located on the canvas:
    - The first bob position (x1, y1) is based on the first angle and rod length.
    - The second bob position (x2, y2) is based on the first bob’s position plus the second angle and rod length.
  3. Draw the current frame (draw function):
    - The canvas is cleared to prepare for the new frame.
    - The rods are drawn as lines from the pivot point to the first bob, then from the first bob to the second bob.
    - The bobs are drawn as filled circles at their calculated positions.
    - The program records the second bob’s position into a "trail" array to keep track of where it has been.
    - It draws the trail as a fading line behind the second bob to visually show the path it has followed, revealing the chaotic motion pattern.
  4. Request next animation frame:
    The program tells the browser to run the update and draw process again on the next animation frame, creating smooth continuous motion.

Summary in plain terms:

Each frame, the program:

  1. Figures out how the pendulum arms should move next based on physics.
  2. Updates the angles and speeds of the arms.
  3. Calculates where the pendulum bobs are now.
  4. Draws the rods and bobs in their new positions.
  5. Draws a fading trail showing the path the second bob has taken.
  6. Repeats this over and over many times per second to create animation.

This loop simulates real physical motion and shows how the double pendulum swings in a chaotic and unpredictable way depending on the starting angles you choose with the sliders.
