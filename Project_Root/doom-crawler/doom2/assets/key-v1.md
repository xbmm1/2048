# Yellow key sprite

Created with the built-in image generation tool and resized to 32 x 32 using nearest-neighbor sampling. Runtime asset: `key-v1.png`. Transparent background and ring hole, dark outline, yellow highlights. Uses one clipped image draw; pickup rules and the simple minimap marker are unchanged.

## Generation prompt

One simple yellow golden key collectible sprite for an 8-bit dungeon crawler matching chunky pixel-art hooded ghosts. Square canvas, true transparent background, centered upright key: large octagonal ring at top with transparent hole, straight vertical shaft downwards, two square teeth pointing right near bottom. Strong dark brown outline, bright yellow main fill, small pale yellow highlights and ochre shadows, only 5 colors, readable silhouette. Pixel art designed on a 32 by 32 logical grid, enlarged nearest neighbor, no antialiasing, no glow, no scenery, no text, no drop shadow, generous 3 pixel transparent margin, flat front view.
