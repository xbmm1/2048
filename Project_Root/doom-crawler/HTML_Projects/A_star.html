Notes & Teaching Points
  • Open set = frontier (nodes to be considered). Closed set = visited/expanded.
  • The heuristic influences exploration; choose Manhattan for 4‑way grids.
  • The tentative path shows how parents create the current best path from start to the currently expanded node.
  • Performance: Using a binary heap for the open set makes A* much faster than sorting every iteration.
